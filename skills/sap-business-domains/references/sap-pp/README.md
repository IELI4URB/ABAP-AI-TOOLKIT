| PLKO / PLPO | Routing header / operations |
| STKO / STPO | BOM header / items |

| MKAL | Production version |

| KBED | Capacity requirements |

| RESB | Component reservations |
| PLAF | Planned orders |
| PBIM / PBED | Independent requirements |
| MDTB | MRP element table |
| JEST | Order status |

## Landscape Decision Guide

| Your Landscape | Use These APIs |
|---|---|
| ECC | Classic BAPIs, FMs, CMOD User Exits, direct table access |
| S/4HANA on-premise | BAPIs + released APIs, BAdIs preferred over exits |
| S/4HANA Public Cloud | Released C1 APIs ONLY, RAP EML, I_* CDS views |
| BTP ABAP extension | RAP BOs, released APIs, clean core mandatory |
| APO PP/DS (classic) | /SAPAPO/ FMs, liveCache, CIF |
| Embedded PP/DS S/4 1709+ | /SAPAPO/ FMs reused, HANA-based |
